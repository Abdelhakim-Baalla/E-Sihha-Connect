# E-Sihha Connect - Frontend

Application React + TypeScript pour la gestion médicale.

## Installation

```bash
npm install
```

## Démarrage

```bash
npm run dev
```

L'application sera disponible sur http://localhost:5173

## Structure

```
src/
├── components/
│   ├── ui/           # Composants réutilisables
│   └── layouts/      # Layouts
├── pages/            # Pages de l'application
├── lib/              # Utilitaires
├── store/            # State management (Zustand)
├── types/            # Types TypeScript
└── services/         # Services API
```

## Technologies

- React 18
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Zustand
- React Hook Form
- Zod
